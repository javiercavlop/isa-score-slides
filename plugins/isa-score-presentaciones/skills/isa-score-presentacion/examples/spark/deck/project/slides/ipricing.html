25

An iPricing represents the offer in a format programs can process, such as YAML, so tools can share it. An iSubscription represents the contracted configuration and the usage state needed to evaluate the subscription at runtime: for example, how many solver runs a customer has used out of those available. Pricing Intelligence turns pricing data into knowledge for decisions; Pricing-Driven DevOps uses these models across development and operation. A-MINT and HARVEY are context only.
