pricing-renderer turns an iPricing into an interface showing plans, features, limits, add-ons and the selection. It is a reusable component, also shipped as a Web Component, which is how Delivera embeds it in its Vue application. The user's selection must be communicated to the app, which validates it and manages the contract. Presenting an option visually does not replace that validation.
