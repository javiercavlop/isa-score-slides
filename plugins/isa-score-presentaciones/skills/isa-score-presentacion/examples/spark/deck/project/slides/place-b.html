Now the functions are placed. Shared capacity fills up and every hop between locations adds latency, so one placement constrains the others. IoT: connected devices that collect data or act. Edge: resources close to the device or the user. Cloud: remote infrastructure. FaaS deploys functions whose execution and resources can be billed by consumption. In CLASP-FaaS we decide where each function of a composition runs, weighing cost, latency and security.
